🛠️ Tools & Resources

Everything you need to put the book into practice: tool setup guides, downloadable templates, ready-to-teach lesson plans, the writing prompts library and CLEAR prompt generator, WriteMentor and TestMentor for students, the multi-agent AI feedback system, professional development materials, and current tool/policy tables.

🛠️ Tool Setup Guides

Step-by-step setup, troubleshooting, and classroom use for every tool named in the book (Google Docs, ChatGPT, Claude, Gemini, Grammarly, LanguageTool, Padlet, SKELL, Hypothesis, Quill).
📄 Templates

Downloadable essay planning templates, the AI Collaboration Log, peer review sheets, and rubric templates.
📝 Sample Lessons

Complete lesson plans for selected chapters with timing, materials, and AI integration notes. Implementation-ready.
💬 Writing Prompts Library

Filterable essay-topic prompt bank by writing type and CEFR level, with per-prompt structure guides, sentence starters, and a copy button.
⚡ CLEAR Prompt Generator

Interactive tool - students fill in five fields (C, L, E, A, R) and the generator assembles a ready-to-use AI prompt.
✍️ WriteMentor

Free, no-login AI writing checker for students. Underlines mistakes by category with plain-English hints, then lets students self-correct before revealing the full answer.
🎯 TestMentor

IELTS/TOEFL-style timed writing practice with AI-estimated band scoring and the same color-coded feedback as WriteMentor. Student ID + PIN login.
🤖 Multi-Agent Feedback System

Teacher guide to deploying the five-agent automated feedback system (Ch 21): setup, anonymisation, grade recording.
🎓 Professional Development

Four-horizon PD framework, PLN-building activity, CLEAR tool evaluation protocol for teacher learning.
🔔 Policy Updates

AI policy updates, tool changes, TOEFL/IELTS scale changes, and Saudi PDPL guidance - kept current post-publication.
📊 Tools Tables

Reference tables mapping tools to stuck points, writing stages, CEFR levels, and essay types. Filterable by category.
